📚 PDF + PowerPoint Reader

Baca PDF, PPTX, dan gunakan OCR untuk dokumen hasil scan

💡 Cara kerja
File PDF akan dibaca menggunakan PDF.js. Jika PDF tidak memiliki teks, halaman akan diproses menggunakan OCR.

File PPTX akan dibaca langsung dari struktur PowerPoint dan teks pada setiap slide akan diambil secara otomatis.

⚠️ Catatan PowerPoint
Versi ini membaca file .PPTX. File .PPT lama belum didukung secara langsung oleh browser. Jika mempunyai file .PPT, simpan terlebih dahulu sebagai .PPTX menggunakan PowerPoint atau aplikasi presentasi lainnya.

✂️ Bagi Teks Langsung

📝 Tempel teks panjang langsung di sini
Fitur ini tidak membutuhkan file. Tempel teks apa saja, lalu pilih ingin membaginya menjadi 2 sampai 10 bagian. Teks akan dibagi berdasarkan jumlah kata dan sebisa mungkin mempertahankan baris serta paragraf.
